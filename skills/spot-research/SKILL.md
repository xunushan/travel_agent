# 调研单景点并生成游览参考

## 技能介绍

围绕一个景点建立完整的游览认知，提供点位比较、到达方式、参考串联、住宿区域与政策信息，帮助用户自行选择点位、比较玩法并规划行程。

输入为单个景点名称，以及用户已表达的出行方式、时段、兴趣等情况；景点内部的观景点、村落和游览区域属于本次调研范围。输出为《单景点游览参考》，说明有哪些点、何时去、怎样到达、游览强度与大致耗时、住在哪些区域方便，以及仍需确认的事项。

## 步骤

```text
1. 生成初始调研大纲
2. 按主题调研
3. 汇总已有信息与新发现
4. 判断是否补充调研
   需要补充 → 调整大纲，回步骤 2
5. 输出单景点游览参考
```

### 1. 生成初始调研大纲

主 agent 按 [research-outline.md](references/research-outline.md) 设计主题，每题列明问题、期望信息与成功标准，开始调研前向用户展示。

先建立整体分布认知，再结合景点特点与用户情况研究点位、玩法与到达方式，不固定题数，不要求每个点位逐项单独调研。只有无法明确对象或形成有意义的问题时才询问用户，不要求补齐固定表单。

### 2. 按主题调研

每次唤起一个子 agent，使用 `xhs-search` 处理一个主题，传入问题与要求；要求包含期望信息、成功标准，以及影响信息取用的用户情况。返回结论文档、关键素材与必要的缺口说明。

- 自驾时，到达信息应包含车辆可达范围、导航目标、停车位置与费用，以及停车后的步行衔接。
- 每个主题返回后立即执行步骤 3、4，再决定下一个主题；已被回答的后续内容不重复调研。
- 下载、笔记、主题报告与本技能输出使用同一文件保存目录 `$ROOT`，不设默认值。

### 3. 汇总已有信息与新发现

主 agent 整合主题报告：

- 建立点位清单与分布关系，比较看点、适合时段、季节条件和游览强度；有独立价值的新点位纳入比较。
- 区分自驾、景交与步行，连接入口、停车位置和实际点位；不同入口或路径分别说明，不拼接成未经证实的走法。
- 比较参考串联方式和住宿区域，说明覆盖点位、耗时与便利性的差异。
- 保留信息的适用点位、时段、交通方式与来源；名称或说法冲突时核对依据，仍无法确认的并列说明。
- 关注报告中来自笔记与评论的新发现，判断是否出现初始大纲未覆盖、但可能影响决策或体验的问题。信息不足时，将具体疑问纳入步骤 4；不为寻找疑问重读全部原始素材。

### 4. 判断是否补充调研

动态调研不使用固定触发清单。结合用户情况、景点特点和出行时段，从实际游览的角度判断：

- 用户可能关注或遇到什么问题？
- 当前信息是否足以支持选择，或帮助用户应对？
- 信息不足是否影响旅行决策或旅行体验？

先检查已有结论，能够回答的直接整合。值得进一步了解且信息不足时，新增或调整主题，明确期望信息与成功标准，回步骤 2 定向调研；新发现也可能是玩法或体验机会，不限于风险与障碍。示例见 [research-outline.md](references/research-outline.md)。

汇总时检查观景点风景照的覆盖：先使用报告素材，再按 `image.md` 附录或 `video.md` 风景画面附录查找，图文描述不足时查看已有低清拼图。缺图且影响景色比较时，集中针对缺失点位设计补充主题，尽量用一次调研覆盖多个内部点位，不机械逐点搜索。补充后仍无可确认素材时保留缺图说明，不用位置不明的照片替代；旧视频不重跑管线补图。

信息足够或影响有限的内容不继续展开。补充后仍无法确认的事项保留未解决原因与影响，不围绕同一缺口重复发起相同调研。尚有必要主题时继续步骤 2，否则进入步骤 5。

### 5. 输出单景点游览参考

按 [reference-format.md](references/reference-format.md) 输出 `<ROOT>/spots/<spot_id>/游览参考.md`。

- 直接输出 Markdown，路线图与风景照在正文直接展示，不生成 HTML 或海报。
- 内容服务于用户选择与实际游览，突出点位差异、到达过程、住宿区域取舍及需要注意的问题。
- 从主题报告的关键素材中选择分布图、路线图与实景照片，按用途与覆盖内容去重；每个观景点有可用素材时提供 1–2 张代表性风景照，近似画面只保留一张。无法确认位置的图片不作为该点位的景色证据。
- 选中图片复制到输出目录的 `assets/`，文件名使用英文字母、数字和连字符，在正文直接展示；输出前检查文件和图片链接。
- 结论注明来源，票价、政策与现状标明年份或日期；缺口与冲突说明其对选择或体验的影响。

## 纪律

- 一次只调研一个景点，不扩展为多个目的地的行程。
- 禁止替用户确定具体路线、编排逐日行程、选定酒店或执行预订；输出参考信息与比较依据。
- 不以全面为由逐点逐项无限搜索；信息足以支持相关决策并应对主要体验问题后停止。
- 存档复用遵循 `xhs-search` 与 `xhs-digest`，不重复下载或理解已有存档笔记，不重跑图片、视频管线。
- 不将个别游客曾到达、历史经验或示例描述写成当前安全可达的证明；无法确认的进入方式说明不确定性，不作为推荐路径。
- 大纲、汇总与补充判断由主 agent 完成；主题调研使用子 agent 调用 `xhs-search`。
