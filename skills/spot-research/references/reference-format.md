# 单景点游览参考模板

## 保存位置

```text
<ROOT>/spots/<spot_id>/
├── 游览参考.md
└── assets/              # 正文引用的图片
```

`ROOT` 与主题调研使用同一文件保存目录。`spot_id` 使用景点简短标识，出行年月明确时可附加年月，如 `zhagana-2026-10`；同一次调研的补充结果更新同一文档。

直接输出 Markdown，路线图与风景照在正文直接展示，不生成 HTML 或海报。模板图片按实际素材保留，无素材时删除示例链接。
