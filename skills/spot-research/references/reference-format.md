# 单景点游览参考模板

## 保存位置

```text
<ROOT>/spots/<spot_id>/
├── 游览参考.md
└── assets/              # 正文引用的图片
```

`ROOT` 与主题调研使用同一文件保存目录。`spot_id` 使用景点简短标识，出行年月明确时可附加年月，如 `zhagana-2026-10`；同一次调研的补充结果更新同一文档。

直接输出 Markdown，不生成独立 HTML 页面或海报。路线图使用 Markdown 图片语法直接展示；风景照使用内嵌 `<img>` 标签，默认 `width="360"`，保持原比例，不设置固定高度，也不改写原图片文件。图片复制到 `assets/`，使用英文字母、数字和连字符命名，输出前检查文件与链接。模板图片按实际素材保留，无素材时删除示例链接。

## 正文写作要求

- **按决策价值取舍**：保留支持点位选择、观景时段、参考走法、到达停车、住宿区域与进入条件的信息，省略无关个人经历。导航岔路、步行衔接等影响实际游览的细节应保留。
- **结论先行，说明分层**：先说明整体分布，再比较点位与走法；各小节先给结论或具体信息，参考走法之后用“参考说明”解释覆盖、耗时与强度差异，多种走法的综合取舍放在“路线借鉴”。缺少信息时不为填满模板补造内容。
- **依据与限制**：保留来源、适用时段，区分事实与建议；影响决策的限制就近说明，未知不写成定论，避免重复泛化免责声明。
- **研究细节**：核查过程、候选取舍、搜索与采集记录留在主题报告或日志，正文只呈现结论。
- **缺口说明**：文末仅列仍影响选择或游览的未知与分歧，简述事项及影响，不重复正文、不列范围外待办。

## 配图要求

- **观景路线图**：与文字走法独立择优、分别标来源，有合适图必须嵌入。优先高清、点位与路径清晰、覆盖主要游览区域的图，同类图去重；原作者走法不同，可用简短图注说明。小景点无图可省略，不补造路线图。
- **点位风景照**：放在对应观景点小节，有合适素材时每点1–2张，优先季节相符、地点可确认的照片。图注明地点、已知季节或时段及来源；无合适素材省略，不留占位图。其他季节图片仅在确有助于说明稳定地貌或视角差异时使用，并明确季节，不用于当季景色判断。
