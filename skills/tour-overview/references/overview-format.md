# 游览总览模板

## 保存位置

```text
<ROOT>/overviews/<trip_id>/
├── 总览.md
└── assets/              # 总览引用的图片
```

`ROOT` 与主题调研使用同一文件保存目录。`trip_id` 使用目的地或线路的简短标识；出行年月明确时附加年月，例如 `gannan-2026-10`，未明确时可使用 `gannan-overview`。同一次调研使用同一目录。
