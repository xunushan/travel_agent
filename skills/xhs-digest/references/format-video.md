# `digest/video.md` 结构契约

**尺度：重。** 同 `image.md`——关键帧上的内容**全提取、不省略**。但**精看的只有关键帧**，
其余时间轴由字幕带与 ASR 覆盖。

**全程站在读者角度**（同 `image.md`）：只写"视频提供了什么信息"，不写"我是怎么把它读出来的"。

## 骨架

```text
# 视频提炼：<标题>

[头部信息栏]

**一句话概括**：<这个视频讲了什么、给了什么信息>

## 关键帧

### digest/assets/frames/<文件>（约 <秒> s）· <这一帧是什么>
1. **一句话概括**：<这一帧给了什么信息>
2. **关键内容**
   - **<方面>**：<内容>
   - …

## 口播要点

按信息类型分行：路线 / 时间与时段 / 价格 / 机位 / 穿搭 / 注意事项 ……
每条注明来自**字幕**还是**口播**。

## 矛盾与异常

**<矛盾点>**
- **矛盾内容**：<两边各说了什么，各自的出处>
- **证据链**：<哪份证据更硬、为什么，结论取哪一份>
```

> ASR 的校正记录**不在这份里**，单独放 `digest/assets/asr-corrections.md`。

## 头部信息栏

放最前，与 `note.md` 同一张表（noteId / 作者 / 发布时间 / 互动 / 原链接 / 解析时间），
外加视频自身的三项：

| 字段 | 说明 |
|---|---|
| 时长 · 分辨率 · 帧率 | `ffprobe` 实测值，**不用元素声称值** |
| 形态 | 口播／烧录字幕带／穿插图卡，各占什么位置 |
| ASR | 引擎 ＋ 实测倍速（**不写**原始转写与抽帧的存放路径——那是内部账） |

## 关键帧

**只保留信息最全面、无遮挡的那一帧。** 同一内容的后续版本（叠加批注层、字幕跳动的重截）
**不单独留帧**，把新增的信息并进那一帧的「关键内容」里；口播里已有的内容也不单独留帧。

**1. 一句话概括**：一句，说清这一帧是什么图、给什么信息。

**2. 关键内容**：全提取，写法同 `image.md`——写内容本体与结构关系（逐行逐站，`名称＝值`），
**不是文字清单**，也不写"我裁了哪个区域才看清"这类过程。

## 口播要点

口播是本类笔记的主要内容来源，**必须成节**。按信息类型分行，**不按时间码顺序抄**——
时间码索引是转写稿的事，`digest/assets/transcript.md` 里有。
**每条注明来自字幕还是口播**：字幕是作者原话（主证据），口播/ASR 是转写（会错）。

## 矛盾与异常

每条按「**矛盾内容**」＋「**证据链**」两行写：先说两边各自说了什么、出处是哪一帧或哪一句，
再说哪份证据更硬、结论取哪一份。**不写评述**，只给事实和取舍。

## 附：`digest/assets/asr-corrections.md`

ASR 校正记录**不写进 `video.md`**（它是一次性的校对账，不是这篇笔记的内容），
单独放 `assets/` 下，结构就一张表：

```text
# ASR 校正记录：<标题>

ASR 在**地名与专有词**上错得系统性，**所有地名均已回字幕／画面复核**。

| ASR 原始 | 校正后 | 依据 |
|---|---|---|
| 数证群海 / 书正全海 / 数正群海 | 树正群海 | 字幕（同一地名三种拼法，不能靠词频） |
| 静海 | 镜海 | 字幕 |
| 建筑海 | 箭竹海 | 站点图 |
| 洛日朗 | 诺日朗 | 字幕 |

其余非地名文字 ASR 与字幕一致，未见需要改动处。
```

**每条都要有依据**（画面 / 字幕），没写依据的校正等于猜。地名同音错误必记——
留着这份，下次遇到同一批地名就不用再校一遍。

## 口播要点

**窗口期**
- 最佳窗口 **10/15–11/10，20 多天**；10 月下旬到 11 月初是「天花板中的天花板」；11/10 后落叶。
- 窗口内：越早树色越单一，越晚水越清澈。

**路线**：7:30 入场直奔镜海 → 右线从后往前 → 中心站换长海线（仍从后往前）→
树正沟从前往后收尾，一天走完三条沟。体力不够只到箭竹海即可。

**机位与时段**：见「关键帧 · 汇总卡」，五彩池补 12:00–14:00（口播）。

**穿搭**：忌大红大紫黄绿与深蓝（撞色／融进湖面），宜米白、浅灰、奶油黄等低饱和浅色，
可小面积点缀酒红／浅蓝／藏青。

**天气与降温**：11 月初仍有降雨概率；该时段降温快，需备薄羽绒服或厚冲锋衣。

## 矛盾与异常

**长海的时段**
- **矛盾内容**：汇总卡写长海 11:00–13:00（t0306）；口播 ［02:54］说「11 点到下午 1 点半」。
- **证据链**：汇总卡是作者最后定稿、整屏拍下的口径，口播是转写且同句字幕与口播一致；
  取汇总卡的 11:00–13:00 为保守值。
