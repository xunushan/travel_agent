# `digest/comment.md` 模板

按以下模板编写，替换占位内容并删除填写说明。

```markdown
# 评论提炼

## 补充信息

<!-- 按内容分组，分组名称依据实际信息确定，例如票务、交通与运营、景点与强度。
每条只写一项有价值的信息，表达简明，注明影响使用的条件及来源。
作者回复标“评论·作者”，其他评论标“评论·昵称”；同一信息多人提及可标“评论（3 人提及）”。
没有补充信息时写“无”。 -->

**<分组名称>**
- <具体信息，例如“冬季右线观光车终点为箭竹海”。> —— 评论·作者
- <具体信息。> —— 评论·<昵称>

## 争议点

<!-- 每项写清说法、质疑或旁证、作者回应及倾向结论，层次清晰、表达简明，避免展开长篇分析。
只保留影响旅行决策的分歧，不复述整条评论。
作者未回应时标“有争议”；有档案信息支持判断时，简述依据，不将推测写成确定结论。
没有争议点时写“无”。 -->

1. **<争议主题，例如“是否每个站点都能随意上下车”>**
   - **说法**：<谁在正文、图片或评论中提出了什么说法。>
   - **质疑或旁证**：<评论者及关键内容。>
   - **作者回应**：<回应内容；没有则写“未回应”。>
   - **倾向结论**：<判断及简要依据；未解决的分歧标“有争议”。>
```
