# `digest/note.md` 结构契约

**尺度：轻。** 这一份只求"够支持检索和快速判断相关性"，细节下次重读 `note.json`。
检索与索引只取这份的"一句话总结"与"内容标签"。

## 骨架

```text
# 笔记提炼：<标题>

[头部信息栏]

**一句话总结**：<一句：主旨是什么 + 提供了什么信息>
**关键信息**
- <维度>：<要点>
**内容标签**：<逗号分隔>
```

**落笔时机：这份是最后写的，不能只从正文抄。**
图文笔记要综合**正文 ＋ `image.md`**，视频笔记要综合**正文 ＋ `video.md`**——
一句话总结、关键信息、内容标签**都**要在读完图卡/关键帧之后再落笔。

**只从正文提炼的 `note.md` 是残的**——正文最省的那部分（作者认为看图就懂的），往往正是读者最想拿的，且只存在于图卡/口播里。

**给了问题时，问题线索决定重点**：这些方位重点写、写具体；读者用得上的其它信息照样写进
关键信息（存档是笔记级的，问题会变）。无问题时按笔记自身主旨写。

头部信息栏读完正文就能填。

## 头部信息栏

放最前。**只留下表这些字段**——形态、所用管线、采集完整度一律不写。

| 字段 | 来源 |
|---|---|
| noteId / 作者 / 发布时间 | `note.json` 的 `noteId` / `author` / `publishedAt` |
| 互动 | `note.json` 的 `stats`——赞 · 藏 · 评 · 转 |
| 原链接 | **只写 `https://www.xiaohongshu.com/explore/<noteId>`**。`note.json` 的 `url` 带 `xsec_token`，那是时效性鉴权参数，抄进去很快失效，**一律剥掉 query** |
| 解析时间 | 本次生成/增补的日期 |

**采集异常不进这张表**——采集范围与完整度是内部账；影响取用的采集问题（视频没声音、
某张图打不开）写进报告 §3。这里只留"这篇是什么"的字段。

## 一句话总结

**综合三样东西写**：标题 ＋ 笔记内容（正文）＋ 图/视频里读出来的内容。

一句说完两件事：

1. **这篇的主旨是什么**——它在讲什么、冲什么问题去的；
2. **它提供了什么信息**——读者能从这篇拿到什么。

- **一句，不换行**；写到"凭这一句能判断这篇跟我的问题有没有关系"为止；
- **直接摆内容**：主旨与关键信息直接写出来，不出现「本篇的主旨是…」「与主旨相关的是…」
  这类元叙述，也不写读了几张图；
- **把来源说成内容**：图卡/口播里读到的东西直接说出来（"最佳时段是…"），不交代它原本长什么样——
  「配一张导览图」「视频里讲了」「正文提到」以及「图卡」「表格」「截图」这类词不出现；
- **写内容本身**，不写内部术语（`有序走法有无` `覆盖维度` `信息密度高`）；
- **不写评价**（`值得一看` `很详细` `干货满满`）。

| | |
|---|---|
| 好 | `九寨沟秋季观景的时序攻略：逐个点位给出最佳时段与最佳机位，并给出一条一天走完三条沟、每个点都卡在最佳时段的路线。` |
| 差 | `一篇覆盖路线/时间/机位三类维度、以有序走法为主线的实测攻略，配图卡一张。` |

## 内容标签

**标签回答"这篇能解决我哪一类问题"——写信息类型，不写信息本身。**
粒度卡在中间：比「九寨沟」「秋季」具体，又要比「观光车 90 元不限次」「进沟时间 9 点半前」
概括。前者是十篇都挂的泛词，后者是随手翻正文就能拿到的一条细节，两者都没有检索价值。

- **参考笔记自带的话题标签**（`note.json` 的 `tags`）看它把这篇归到哪类内容上，但平台标签
  多是营销词（`#人生必去的景点`、`#旅游编辑部`），能用的不多，不要照抄；
- **一条标签 = 一类信息**，例如 `游玩路线`、`乘车攻略`、`徒步路段`、`打卡点`、`最佳时段`、
  `最佳机位`、`拍照穿搭`、`窗口期`；
- **落标签时排除两类**：
  - 泛词：泛地点（`九寨沟`）／泛时节（`秋季`、`10月下旬`）／泛体裁（`一日游`）／评价词；
  - 具体细节：点位名（`五花海`）、具体数字（`观光车90元不限次`、`进沟时间9点半前`）、
    单条结论（`犀牛海与老虎海易错过`）——这些属于正文，不属标签；
- **5–8 条**，宁少勿滥，同一类不拆成两条。

| | |
|---|---|
| 好 | `游玩路线` `乘车换乘` `徒步路段` `打卡点` `最佳时段` `最佳机位` `拍照穿搭` |
| 差（泛） | `九寨沟` `秋季` `攻略` `一日游` |
| 差（碎） | `犀牛海与老虎海易错过` `观光车90元不限次` `进沟时间9点半前` `五花海老虎嘴` |

```text
**一句话总结**：九寨沟一日游的实测走法——从沟口到盆景滩 14 段乘车与徒步交替的路线与
换乘顺序，点明哪 4 段值得徒步、几点进沟最合适，并给出全部乘车点的上/下车站与 9 处必打卡点位。

**关键信息**
- 路线：右线（日则沟）→ 诺日朗中心站换左线（则查洼沟）→ 回诺日朗瀑布徒步 → 树正沟徒步出沟，
  共 14 段；其中 4 段明确建议徒步。

- 徒步量与强度：全程约 2–3 万步，作者称缺乏运动的上班族走一天也不累。

**内容标签**：游玩路线, 乘车换乘, 徒步路段, 打卡点, 游览时段
```
