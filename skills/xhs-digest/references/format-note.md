# `digest/note.md` 模板

按以下模板编写，替换占位内容并删除填写说明。

```markdown
# 笔记提炼：<标题>

<!-- 头部只保留以下字段，不写素材形态、所用管线或采集完整度。 -->

| 字段 | 内容 |
|---|---|
| noteId | <note.json 的 noteId> |
| 作者 | <note.json 的 author> |
| 发布时间 | <note.json 的 publishedAt，注明时区> |
| 互动 | <note.json 的 stats：赞 数量 · 藏 数量 · 评 数量 · 转 数量> |
| 原链接 | https://www.xiaohongshu.com/explore/<noteId> |
| 解析时间 | <本次生成日期> |

**一句话总结**：<用一句话概括笔记主题及提供的主要信息，例如“九寨沟冬季一日游走法，包含乘车与徒步顺序、值得徒步的路段及入园时段建议”。>

**关键信息**

<!-- 按内容组织要点，层次清晰、表达简明，保留影响旅行决策的条件及限制。
每条直接写结论，不写信息覆盖清单或提炼过程；必要时标明作者说法、评论来源或争议。
不在此重复图片、视频与评论文档的全部细节。 -->

- **<方面名称>**：<该方面的主要信息，例如路线顺序、换乘方式或徒步路段。>
- **<方面名称>**：<该方面的主要信息及适用条件，例如冬季运行范围。>

**内容标签**：<逗号分隔的信息类别，例如游玩路线, 乘车换乘, 徒步路段, 游览时段>
```
