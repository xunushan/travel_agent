# 踩坑

用 discover / download 时**出问题了怎么做**。症状对不上时从末尾的「常见的报错」往下找。
页面结构本身的记录不在这里——那些是改代码时看的，写在 `locators.yaml` 和脚本注释里。

## 1. 搜索返回 0 条候选

先看 stderr 那一行的**耗时**。结果页是客户端渲染的，脚本会等到「本次关键词的结果页上出现了搜索
卡片」才抽卡（`render_timeout` 默认 45s）：

- 真等不到 → 它报超时，并把最后看到的 URL 打出来；按那个 URL 判断卡在哪（没登录、没导航过去）。
- 几百毫秒就结束、`source.url` 又不是结果页 → 页面根本没动过，不是「没有结果」。

0 条也可能是页面上确实没有：换个词，或看清单里的 `applied`——筛选筛得太狠也会一条不剩。

自己手工敲 `chrome-agent` 时容易踩同一个坑：`tabs navigate` 是异步的，紧接着抓的快照还是上一页，
而 explore 首页与结果页是同一套卡片标记。

## 2. 评论读不全（只读到十来条，怎么滚都不动）

Chrome 对后台标签页降频，下一批评论正由那个被降频的事件循环追加。脚本采集期间会自己
`tabs activate`，所以还遇到这个症状，多半是标签页又被别的程序切走了（窗口最小化也算）：
让窗口留在前台，重跑 `--part comment`。

`warnings` 里的「评论只读到 N 条（页面声明 M 条）」是另一个成因：未登录，或评论区没加载完。

## 3. `parts` 出现「未完成」，或报告里有 `warnings`

**同一篇重跑一次**就够了：盘上已有的不会再下，只补缺的那些。逐条处置：

| warning | 怎么做 |
|---|---|
| 未找到笔记首图，未能落封面 / 封面下载未完成 | 重跑补。反复失败多半是链接里的 token 过期了，回 discover 搜一次拿新链接 |
| 未识别出笔记原图，已拒绝下载小图/表情/评论配图/页面资源 | 这是**主动拒绝**了可疑图，不是网络问题：确认打开的确是笔记详情页 |
| 存在当前无法直接下载的 blob/HLS/DASH/unsupported 媒体 | 视频直链没拿到，重试也没用。这一篇的 `video` 会报**未完成**（`FAILED`），不是「无此件」——别当成这篇没有视频 |
| 评论可能未读全 / 滚动达到 N 步上限 | 见第 2 条。重跑会重采（不完整的评论算缺口） |
| 正文达到采集上限，可能不完整 | 正文极长被截断，重跑结果一样；要看全文只能手工开页面 |
| 下载完成但找不到文件，未归档 | 文件被移走或权限问题。这一条下一轮会重下 |

## 4. `note.json` 里部分字段为空是正常的

元数据**状态优先、DOM 兜底**，这次用的是哪个源记在 `capturedFrom`。以下字段拿不到就是空，
不代表下载出问题：

- `updatedAt`：只有状态里有，也是判重的主证据。为空时判重退到按内容指纹比较。
- `stats.shares`：只有状态里有，页面不印分享数。
- `ipLocation`：页面本来就不是每条都有。
- `publishedAt`：纯 DOM 路径下由 noteId 前 8 位解出，只能精确到天。

## 常见的报错

| 报错 | 含义与处置 |
|---|---|
| `the following arguments are required: --keyword` | discover 缺搜索词（`--list-filters` 时不需要） |
| `点了「X=Y」但页面没有把它标成生效项` | 筛选没施加成功，脚本已中止。先 `discover.py --list-filters` 看真实选项 |
| `筛选弹层打开了，但里面一个选项也没读到` | 页面改版，改 `locators.yaml` 里 `search.filter_*` 那一段 |
| `没有可重放的详情页 URL（索引里也没有）——先 discover 再下载` | `--note-id` 只给了 id，盘上也没存过带 token 的链接。别拼 URL，回 discover 拿一次 |
| `有件没下成：image=…` | 见 [flow.md](flow.md#21-输出)。这条是 `FAILED` 并以非 0 退出，理由点名是哪件 |
| `Tab not found: N` | 标签页已关。重新 `tabs list` 拿 id |
| `详情遮罩仍开着：关闭控件不可见` | 关掉遮罩再跑（按 `Escape`），或换一个标签页 |
| `下载完成但找不到文件，未归档：<path>` | 见上面第 3 条 |
| 评论只读到十来条、怎么滚都不动 | 见上面第 2 条 |
| `Receiving end does not exist` 一类传输层报错 | `runtime.chrome_agent` 已自动重试；`download.py` 另有一次重启浏览器后重试整篇（认得 daemon 掉线的几种报错） |
