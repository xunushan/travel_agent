# 结论文档模板

按以下模板填写，删除说明与占位内容。

## 结论文档：answers/<question_id>.md

```markdown
# <问题>

## 结论

<!-- 按要求组织小节，每项写结论及适用条件，标注 noteId；多篇支持时列出相关来源。
冲突说法分别列出，时效性信息注明年份，不重复提炼过程。 -->

### <要求中的方面>

<结论、条件及必要限制。>（来源：<noteId>）

## 关键素材

<!-- 每项使用复制到 answers/assets/ 的图片路径，提供用途与原件来源。
在满足要求的前提下最小化数量；无可用素材时写“无”。 -->

![<图注>](assets/<question_id>/fig1-<slug>.<扩展名>)

<一句话说明用途；复制的图片转正时注明“已转正”。>

原图：`<原件路径>`（来源：<noteId>）

## 缺口

<!-- 没有缺口时省略本节；有缺口时与 run 日志的 gaps 保持一致。
列出影响回答的未确认项、尝试与未解决原因。无法确认的名称关系须附判断依据及出处。 -->

- **<未确认项>**：<已尝试什么、为何未能确认、相关依据及 noteId 或存档路径。>
```
