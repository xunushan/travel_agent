# 搜索词与搜索条件指南

**输入**：问题、要求、已有结论及剩余缺口。

## 搜索词

根据问题与要求确定关键词，围绕尚未回答的内容调整关键词。

- **对象＋所需信息**：如“扎尕那 分布图”“扎尕那 门票价格”。可参考搜索页推荐词：导航定位、门票价格、路线图、分布图、实况、照片、最佳时间、看日出、攻略、自驾、海拔。
- **优先具体表达**：避免单用“旅游攻略”等泛词，直接写要查的内容，如路线、游览时间或路况。
- **每轮一个词组**：不将多个独立查询合并搜索。
- **围绕缺口换词**：利用已读笔记中的新地名、相关表达及报告缺口，不重复搜索已有充分结论的内容。
- **减少偏题结果**：搜索结果与问题不符时，在关键词中写清目的地和要查的内容，例如将“甘南 自驾”改为“甘南 自驾路线”；需要特定月份的信息时加入月份。

## 搜索条件

当前可用选项以 downloader 的 `--list-filters` 输出为准。

| 维度 | 选项 | 选择建议 |
|---|---|---|
| 排序依据 | 综合、最多收藏、最新、最多点赞、最多评论 | 路线、攻略、口碑与常见观赏窗口优先最多收藏；当年观赏进度、近期路况、人流与天气优先最新；高互动评价可选最多点赞或最多评论；无明确偏好时可用综合 |
| 笔记类型 | 不限、视频、图文 | 找图集、路线图或图文说明可选图文；找实地画面可选视频；信息形态不限时不筛类型 |
| 发布时间 | 不限、一天内、一周内、半年内 | 路线、分布、时长、口碑与常见观赏窗口通常不限；观赏窗口在搜索词中带月份；当年观赏进度、近期路况与人流选一周内；近期天气选一天内 |
| 搜索范围 | 不限、已看过、未看过、已关注 | 通常不限，需要关注账号的内容时选已关注 |
| 位置距离 | 不限、同城、附近 | 通常不限，需要当前所在地周边内容时选同城或附近 |

- **条件调整**：无关结果较多时，按问题收紧地域、时段或类型；条件过严、缺少可用候选时，放宽非必要条件，保留问题要求的地域与时效限制。

## 纪律

- **候选数量**：top-k 默认 6，最多 6。候选少时先判断已有内容，必要时换词，不为凑数量增加 top-k 或放宽条件。
